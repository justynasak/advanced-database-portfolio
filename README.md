# MIT 8103 Advanced Database Systems Portfolio

## Selected Case Study
**Organisation:** NaijaMart, a simulated online retail platform operating in Nigeria.
**Nature of system:** Multi-category e-commerce marketplace where customers browse products, place orders, pay online, and track delivery.
**Users:** Customers, sellers/admin staff, delivery agents, and the finance team.
**Major data:** Customers, addresses, categories, products, orders, order items, payments, deliveries, and stock levels.
**Key operations:** Register customers, add products, place orders, update stock, process payments, track delivery, and report on sales.
